# Twitch Big Data Analytics Using the Twitch API and Google Cloud Platform
Developed an end-to-end big data analytics solution that collects Twitch data through the Twitch API and processes both real-time and historical data on Google Cloud Platform (GCP). Designed separate streaming and batch-processing pipelines to transform raw data, store it in BigQuery, support machine learning workflows, and deliver actionable insights through interactive BI dashboards.

## Architecture and Key Contributions
- Integrated the Twitch API to collect streaming and historical platform data.
- Used Google Cloud Run to support scalable API-based data ingestion.
- Built a real-time pipeline using Apache Kafka and Apache Spark running on Google Cloud Dataproc.
- Created a historical data pipeline using Google Cloud Storage and serverless Cloud Dataproc.
- Processed and transferred structured data into BigQuery for centralized analytics.
- Supported machine learning workflows using Vertex AI and data stored in BigQuery.
- Developed BI dashboards in Looker to visualize trends, performance, and audience insights.
- Designed a scalable GCP architecture combining data engineering, big data processing, machine learning, and business intelligence.
